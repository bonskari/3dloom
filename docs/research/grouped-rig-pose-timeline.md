# Grouped rig pose timeline

Full-rig capture now persists a `pose_frames` event list on each LoomRig. Old documents default to an empty list. The validated type rejects nonfinite, unordered, duplicate and too-close times using the same time tolerance as transform tracks. Existing mapping edits retain the event list; file merge/remapping retains it through the existing complete rig clone.

The separate Animation Editor shows a Pose row for rigs with captured events. Dragging a marker submits one `MoveLoomRigPoseKey` command on release; Escape cancels a pending drag. The context menu submits `DeleteLoomRigPoseKey`. The main UI remains unchanged while the editor is closed.

The commands prepare all edits on copies before committing one Undo group. They move or remove actual owned control PRS keys at the event frame, base blend keys, the three authored pose-offset channels, affine matching keys and contact keys. Original bone tracks are excluded and bone IDs used as controls are rejected. Existing key values and tangents are retained. A destination collision in any affected channel rejects the whole move, even without a full-pose marker at that destination. Protected tracks and XRef Scene controls reject before any live change. Times must fit the same integer-timeline range as contact/blend authoring.

These events group the rig keys currently present at a frame; they are not duplicate baked animation snapshots. Independent channel editing can change which keys remain in a group. Freezing all rig controls removes empty events, but preserves events with actual remaining locked channel keys. Undo restores metadata and node tracks together.
