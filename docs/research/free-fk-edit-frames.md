# Matched Free FK input frames

A bent IK pose released to Free carries affine matching after its FK input. The previous edit path treated that post-correction as part of a left-hand parent frame. World rotation, move and absolute orientation consequently used the wrong coordinate system. Four regressions reproduced the wrong world rotation, translation, typed orientation and Gimbal-channel edits on a genuinely nonidentity matched pose. The fixture enables IK before moving its goal, because switching blend intentionally matches the visible pose.

The scene now converts through `base * input * post`: source bone/parent/rest on the left, current pose corrections on the right. World editing removes both sides in their actual order. Pivot/child-compensation composition uses the matching forward conversion. Absolute world orientation also uses this conversion for FK inputs. Parent/Gimbal axes refer to the frame before the stored input, so a Gimbal edit changes the intended Euler channel. Imported bone tracks and the matching data are not rewritten to conceal the error.

The four focused tests pass across the three joints, including Undo and source track retention. The production Ray opt-in additionally bends/releases each real limb, edits all three FK controls, checks world orientation and pivot preservation, and verifies source/rig metadata after Undo.
