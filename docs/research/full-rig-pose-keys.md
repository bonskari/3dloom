# Full-rig pose capture source checkpoint

`KeyLoomRigPose` records the current frame into the characterized rig's owned FK, master, goal and pole transform channels and its blend, pose-offset, affine matching and active contact channels. Active contact positions/rotations are keyed in the contact track rather than redundant raw helper tracks. The button appears only in the separately opened Animation Editor.

Source bone tracks are not implicitly keyed. Skin geometry, influences, materials and unrelated scene nodes are retained. A control ID that points at a source bone is rejected. Protected tracks are skipped when unchanged and reject a changed draft. Unsupported procedural controllers reject capture instead of silently losing the pose.

In Set Key mode, the command prepares edits against a read-only reconstruction of the live pose baseline. It captures pending node edits under the existing key filters, plus pending rig metadata when IK parameters are enabled. All preparatory validation, including XRef Scene protection, occurs before discarding the live preview. The accepted changes form one Undo step and establish a fresh pose baseline. A rejected draft retains the current preview and its history.
